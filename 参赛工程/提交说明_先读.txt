  自研代码在哪里.txt：区分官方主体、自研算法、集成设置和验证适配。
  开发源码/passes/opt/pmux_opt.cc：实际编译进候选的完整新增 pass。
  构建工具/PMUX优化补丁.patch：相对同基线原版源码的完整自研/集成补丁。
  一键复验.py：从解压目录运行当前版本的配置、面积、EQY 与性能复验。
  当前验收指标.json：只汇总本次 B 臂 F4c 的面积、EQY、三批预定性能。
  正式文档：本次更新的技术文档、完整设计文档。

三、解压后怎样运行
环境要求：Windows x64；已安装 Python 3.10 或更新版本、完整 Git for Windows。
官方 EDA 和 EQY 运行组件已在包内，不需要原电脑的项目目录。
这个最小闭包已验证本包实际采用的 EQY/Yosys SAT 策略；未包含全部第三方
SMT 求解器。若主动更换验证策略，需要另行提供该策略要求的官方求解器。
不要单独移动 yosys.exe；保留本目录结构。先在本目录打开终端，执行：

  python 一键复验.py --阶段 配置
  python 一键复验.py --阶段 等价

“等价”会实际重跑九例两版面积，再运行真实 EQY；不是读取旧 PASS 冒充新运行。
结果自动保存到代码包目录旁的“复验输出/时间戳”，不会覆盖提交证据。
仅面积：python 一键复验.py --阶段 面积
完整测量：python 一键复验.py --阶段 全部
性能单独复测需要先前等价结果，可按“一键复验.py --help”使用 --已有证据。
性能复测时请关闭其他综合、仿真、编译等负载；本地耗时受机器和运行环境影响。
可用 --输出目录 指定一个尚不存在、位于代码包目录之外的新目录。

Git 若未在 PATH/常用安装位置，可在当前 PowerShell 中设置：
  $env:PMUX_GIT_USR_BIN = 'E:\工具\Git\usr\bin'
这只是示例路径，请换成本机实际 Git 安装目录。入口不会修改系统 PATH/注册表。
普通 Yosys/Tcl 自定义运行可使用：
  python 验证脚本/配置与启动.py --程序 优化版 --version

四、已验证的结果与边界
正式九例面积由 2389 降至 2115，逐例下降百分比的算术平均为 14.0805%；
总量下降为 11.4692%。这两个统计量不同，不能混用。
九例均无面积反增，DFF 和顶层 I/O 不变；真实官方 EQY 为 9/9 PASS。
预定01、02、03为三批正式性能证据，包含52个候选原始测量样本；按预定规则
选用初测或五对重测平均后，三批九例的时间和主进程峰值内存增幅均不超过5%。
配置自检、迁移复验或其他诊断不是第四批正式性能测量，也不是新增性能成绩。
本地验证不等于组委会最终认证；重复测量数值不保证与历史记录完全相同。

五、官方与自研边界
新增 pmux_opt 为本项目自研。Yosys/ABC/EQY/SBY/Icarus/GNU Make 为官方软件；
ABC F4c 是统一使用官方 ABC 的参数设置，不宣称其为本项目发明的算法。
其它标准 pass 次序保持不变，只在原有 peepopt/opt_clean 后、cmp2lut 前插入
新增 pass。默认不启用索引化、移位、谓词常量化或极性等研究开关。
源码保留默认关闭研究代码，保证源码与实测二进制一致；不把失败候选当正式版。

七、从源码重建
安装 Visual Studio 2022 C++ Build Tools、CMake 3.28+、Ninja 后，运行：
  python 构建工具/便携编译.py --输出目录 "E:\临时构建\PMUX新构建"
  python 构建工具/便携编译.py --原版 --输出目录 "E:\临时构建\原版新构建"
输出目录必须尚不存在且位于代码包外。本包没有重新编译算法来规避身份绑定；
便携编译脚本仅用于用户自主重建。正式源码内的必要英文文件名不改名。
