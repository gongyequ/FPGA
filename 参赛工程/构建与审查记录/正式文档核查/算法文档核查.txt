二、正式算法执行顺序与综合入口

最终 synth_intel 在官方 coarse 流程中保留原有顺序：
  opt → wreduce → peepopt → opt_clean
  → pmux_opt -order-decode -flatten-fallback -uniform-abc -flatten-data-arm
  → techmap -map +/cmp2lut.v -D LUT_WIDTH=4 → opt_expr → opt_clean
随后继续官方 synth_intel 流程。没有在 ABC 之后自研重构 LUT，没有改写官方 ABC9 pass，也没有按用例名挑选算法。

pmux_opt 内部正式执行顺序：
  1. 若启用 uniform-abc 且用户没有明确给 abc9.script，则设置统一脚本。
  2. 遍历选中模块，跳过 blackbox；没有选中 PMUX 的模块在分配 SigMap/谓词表前提前退出。
  3. 为必要谓词建立驱动索引，逐 PMUX 检查端口维度。
  4. 删除已证明为常量零的选择臂；同步重建 B/S。
  5. 同控制字译码 B/S 成对稳定升序排列。
  6. 相同输出位列共享。
  7. 释放第一阶段别名表后，执行 A/default 嵌套吸收。
  8. 再执行 B/data 嵌套吸收。
  9. 输出各规则实际命中数。研究开关均未在正式调用中打开。

重要：统一 ABC 脚本设置发生在模块提前退出之前，因此无 PMUX 的电路仍使用同一候选 ABC 脚本。不得写成“无 PMUX 时恢复原版映射”或“零结构命中即没有任何效果”。

正式统一 ABC 命令：
  &dch -f -r; &if {W} {D} {R} -a -v -F 4 -c; &mfs
Yosys scratchpad 存储形式：
  +&dch,-f,-r;,&if,{W},{D},{R},-a,-v,-F,4,-c;,&mfs
本轮九例各一次外部 ABC 进程、一次 &if 映射调用；-F 4 表示 area-flow 迭代参数，不是四次 ABC 进程或四套映射择优。
-c 是 ABC 的真值表/叶输入排列相关内置机制，不能扩称实现完整 NPN 规范化或保证任意电路资源减少。需要详细解释时引用固定 ABC 源码的具体选项实现。
用户明确设置 abc9.script 时，本 pass 尊重覆盖；这种运行须独立绑定脚本身份并重新验收，不能套用本轮 F4c 成绩。

三、公式约定与官方四态 PMUX 语义

定义 P(A,B,S) 为官方 $pmux：A 和 Y 宽 W，S 有 K 位，B 有 K 个 W 位数据臂。
本文 [U,V] 表示 RTLIL SigSpec 的低位优先 append：U 在低索引，V 随后；不是未经说明的 Verilog {U,V} 高位拼接。公式中的 B 与 S 顺序必须一致。

依据固定源码 techlibs/common/simlib.v 的 $pmux 模型：
  · 未出现 1 或 X 选择时，输出默认 A；选择 Z 没有 case 分支，在该官方模型中被忽略。
  · 恰有一个 1、其余选择为 0/Z 时，输出对应 B 数据臂。
  · 任一选择 X 或两个及以上选择为 1 时，输出全 X。
  · 被选中的 A/B 数据含 Z 时，Z 可以传递；不能把数据 Z 当零。
这描述的是所核查官方 PMUX 模型，不能泛化为所有 Verilog mux/三目运算符的语义。

因此：单臂 PMUX 仍保留 PMUX；即使 A==B，也不能以普通 $mux 替换或删除。只有 SigMap(S[i]) 恰为 S0 才删除该选择臂，Sx、Sz、动态信号均不删除。全部选择臂删除时连接 Y=A。
列共享仅当规范化后的 A 位以及每一个 B 臂的对应位均相同时成立；共享输出位跟随同一选择表达式，在 X/Z 下也一致。每位至多与前 256 个独特列代表比较，这是工程上界，可能错过更远的可共享列，不是放宽一致条件。

四、A 臂/default 嵌套吸收：正式规则

原结构：
  I = P(Ai, Bi, Si)        // 内层 K 个选择臂
  Y = P(I, Bo, So)         // 外层 M 个选择臂，I 接外层默认 A
构造窄控制 PMUX：
  G = P(Si, 0^(K*M), So)  // 输出宽 K，M 个全零数据臂
替换：
  Y' = P(Ai, [Bi,Bo], [G,So])

语义检查：So 全 0/Z 时 G=Si，输出退回内层；外层恰一个 1 时 G 全零，只保留原外层选中数据；So 含 X 或多选时，原 So 仍进入最终 PMUX，原先的 X 行为得到保留。G 必须使用 PMUX，不能随手改为 Si & ~|So。

识别与拒绝条件：
  · 同一模块，内外均为选中且端口维度一致的 PMUX，内层不是外层自身。
  · 规范化后的外层 A 完整等于内层 Y；部分位、逆序、拼接不匹配均拒绝。
  · 内层每个输出位均为线网，规范化后使用次数恰为 1，没有 PMUX 驱动歧义。
  · 顶层/模块输出视为使用者；已知单元输入及未知单元所有连接均计入使用数。
  · 标记为 pmux_opt_control_gate 或 pmux_opt_data_gate 的辅助门不再作为被吸收的内外层。
  · W>K 且 K+M≤16；这依据结构，不依据用例文件名、顶层名或期望答案。
  · 每次成功重写后重建连接信息；每模块 A 规则最多执行 32 次。
  · 本规则会先检查是否存在完整 fallback 嵌套边，再分配全模块使用计数表。

边界说明：驱动歧义表是 PMUX 输出驱动表，不是任意非法多驱动网表的完整证明器；正确输入与官方流程检查仍是前提。规则删除一个宽内层 PMUX、添加一个窄控制 PMUX，因此 PMUX 单元总数不一定减少，收益以官方后续映射结果为准。

五、B 臂/data 嵌套吸收：本轮新增正式规则

原结构：
  I = P(Ai, Bi, Si)              // 内层 K 个选择臂
  Y = P(Ao, [...,I@j,...], So)   // 外层 M 个选择臂，I 接外层第 j 个 B 臂
构造两个窄控制 PMUX：
  H = P(1, 0^K, Si)             // 输出宽 1，K 个零数据臂
  V = [H,Si]                    // 默认臂选择 H 在低索引，随后为 K 个内层选择
  T = P(0^(K+1), V, So[j])      // 输出宽 K+1，只有一个选择臂，仍是 PMUX
替换外层第 j 臂：
  原来数据 I、选择 So[j]
  改为 K+1 个数据臂 [Ai,Bi]、K+1 个选择 T。
外层 Ao 及其余 B/S 臂保持原顺序。最终外层选择臂数为 M+K。

四态解释：
  · So[j]=0/Z 时 T 全零，内层不影响外层，与原结构一致。
  · So[j]=1 时 T=[H,Si]。Si 全 0/Z 时 H=1，选择 Ai；恰一个内层 1 时 H=0，对应 Bi 被选中；Si 含 X 或多选时，H/Si 使最终输出保持原 X 结果。
  · So[j]=X 时 T 全 X，即使内层数据相同也不会误变成已知值。
  · 其他外层选择仍原样存在：额外的 1 或 X 继续产生原多选/未知结果。
  · 所选数据的 Z 保持可传递。H 不能以 ~|Si 替换，T 不能以按位 AND 或普通 mux 替换；Z 选择和 X 合并语义会不同。

识别与拒绝条件：
  · 同模块、选中、合法 PMUX 维度，W≥1、K≥1、M≥1。
  · 外层第 j 个完整 B 切片的规范化信号恰为内层完整 Y；不接受部分、乱序或重复位别名造成的非完整连接。
  · 内层输出每位为线网、使用数恰为 1、无 PMUX 驱动歧义；额外扇出或模块输出曝光均拒绝。
  · 内层不等于外层；内外均不能带两类辅助控制门标记。
  · W>K+1 且 M+K≤16；每次吸收后重新判断，不能只检查最初一次。
  · H、T 带 pmux_opt_data_gate 标记；成功后删除宽内层 PMUX，重建连接信息；每模块 B 规则最多 32 次。

A 与 B 是两个各自有界的循环，不能写成“所有嵌套合并合计最多 32 次”；本次最多 32 次 A 加 32 次 B。B 规则每次引入两个窄 PMUX、删除一个宽 PMUX，PMUX 数量可以增加 1。这不等于映射后的 LUT+NOT 增加；也不能据此承诺所有任意输入必有面积收益。

六、同控制字 order-decode 规则

predicate_constants 只抽取一位 $eq 或 $logic_not 输出为 1 时成立的确定 0/1 事实：
  · $eq 先按 max(A宽,B宽) 扩展；仅 A_SIGNED 与 B_SIGNED 同为真才符号扩展，否则零扩展。
  · 必要时交换常量侧；比较常量含 X/Z 则拒绝。重复控制位的事实矛盾或常量位不一致则拒绝。
  · 比较宽度 1..1024；$logic_not 对应控制各位等于零的事实。
  · order-decode 对每臂要求同一组规范化控制位，事实数最多 32，驱动为不歧义的已识别比较器。
各臂事实按 SigBit 规范顺序排列，计算其二进制常量码；按码稳定升序排序，并同时移动对应 B 切片和 S 位。
相同码维持原相对顺序，既不合并重复比较器，也不假设 one-hot。A、Y、臂数和原选择集合不变；不是改变优先级。
控制位的规范排序不一定等于用户源代码的自然总线位序，不要把此规则误写为完整四位 natural-order 索引变换。
order-decode 的连接改写本身保持 PMUX 语义；最终面积变化来自后续映射启发式，不是通用严格面积单调定理。

七、开关与正式/研究边界

独立执行“pmux_opt”时，所有可选 bool 开关初值均为 false；基础零选择臂清理和相同列共享始终执行。
正式 synth_intel 显式启用四项：
  -order-decode：同控制译码 B/S 稳定升序。
  -flatten-fallback：A/default 嵌套吸收。
  -flatten-data-arm：B/data 嵌套吸收，本轮正式启用。
  -uniform-abc：设置统一 F4c ABC 脚本，尊重明确的外部覆盖。

保留在源码但正式默认关闭：
  -index-full-x：完整 4 位自然位序译码索引；16 个完整唯一码、数据宽 1..32、A 全 Sx、同 4 个不同动态控制位，表格按 2 的幂步幅填充 X，总表宽≤512，生成官方 $shiftx。它是研究实现，不是本轮正式功能。曾有集成研究版 RAR1 288→321 反增而被拒绝，不能放入正式架构主路径或成绩归因。
  -shiftx-small：只对受限 2/3 位、3..7 臂、至多缺一个码的密集译码通过守卫后调用官方 pmux2shiftx -norange；全 X 默认在该规则中有面积拒绝条件。它不是自制替代 shift 引擎，也不是本轮正式变换。
  -const-decode：在某 B 臂中传播该选择比较成立时的控制常量，A、S、PMUX 类型不变；关闭。
  -const-polarity：只处理 0/1/X 常量 A/B 表，排除动态和 Z；B 的 1 多于 0 时翻转已知 0/1并增加真实输出 NOT；X 保持，有标记防重复；关闭。
  -desc-order：改为稳定降序，必须同时启用 -order-decode，否则报错；关闭。
  selection：只处理选中模块/单元；本轮综合正常全设计选区，不是按官方用例挑选。

已发现文案残留：help() 将 -flatten-data-arm 称“optional research rule”，与本轮 synth_intel 已显式启用不一致。文档以实际调用和日志为准，并可说明该帮助行沿用了研发时期描述。不要为修正文案偷偷重编/替换已绑定程序；若改程序须新身份重验。

九、正式综合、面积与效率口径

主入口仍为 read_verilog（本工具使用 -sv 兼容读取给定 .v）、hierarchy -check -top TOP、synth_intel -family cycloneiv -top TOP；两版用同样输入/参数/工具环境。候选额外 pass 由其 synth_intel 内部调用，用户不必另手工插命令。
面积/证明截面使用：synth_intel ... -run begin:map_cells；停止于 map_cells 标签开始前，已执行 ABC9 及其后的清理/命名，尚未将通用 LUT 映射到最终 cycloneiv 器件原语。
面积是该截面顶层 $lut 加 $_NOT_/$not 的数量，DFF 和 IO 不计入优化分子，但逐例核对不变。存在未实例化的器件库/辅助模块不等于非法层次；不得要求 JSON 必须只含一个 module。必须拒绝顶层活跃未展开设计子模块或意外单元类型。
评分面积为九例分别计算 (原版-优化版)/原版后的算术平均≥10%，同时九例无反增；总量减少比例另列。不能把平均比例写成总 LUT 总数下降比例，也不能称每例都减少≥10%。

效率为完整 Yosys 启动到退出的 Windows 墙钟时间，包含 read/hierarchy/完整 synth_intel/stat 与等待 ABC；没有用面积截断运行代替完整效率流程。
内存是同一次 Yosys 主进程 PeakWorkingSet，不是采样瞬间 RSS，不是两进程内存之和，不包括单独加上的 ABC 峰值。此选择必须披露。
