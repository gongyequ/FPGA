更新内容
加入7张正式设计文档截图素材（首页、架构、B臂变换、公式、执行流程、验证范围、实测表）。
截图由正式PDF以240dpi渲染后裁剪，不改字；架构图展示时另外裁去图外下方标题区。
新增Tcl四项开关说明、C++命令注册、成本守卫源码、选择行为表、原始统计与验证依据。
镜头中的截图标注来源页码；截图来源与哈希保存在“文档截图/截图来源.json”。

配音
将MP4导入剪映，对照“配音稿_带时间点.txt”逐段录音。
配音稿共12段，区间与视频完全对应；这是预设配音区间，不是已录语音自动对齐结果。
如要加片头片尾，成片总长仍须控制在3分钟内。
画面素材文件夹保留每个镜头的高清图，可根据自己的语速调整局部停顿。

证据与表述
视频是基于真实代码、文档和已有运行记录制作的讲解画面，不是现场终端录屏。
ZIP04 LUT 371→292，下降21.29%；总cells 387→308；触发器16→16；IO位数115→115。
九例逐例降幅平均14.0805%，资源总量2389→2115、总量下降11.4692%，无单例反增。
整体收益来自通用PMUX规则与统一官方ABC映射配置，不全归因于一条B臂规则。
EQY证明基于ABC后网表、受限dffeas逆适配、opt_clean和setundef -zero -init，已知初值保持。
PASS表示这一验证配置下功能等价，不表示网表文本相同或组委会最终认证。
本次只制作视频，没有将既有九例记录说成本次重新运行，也不增加新的测试成绩。

重新生成（Windows；Python3.10或更新）
在本目录执行：
  python -m pip install --target 制作工具 pillow imageio-ffmpeg==0.8.1
  python 制作增强版.py
  python 制作增强版.py --render
生成前若同名MP4存在，先另存旧成片。系统字体为Microsoft YaHei和Consolas，不在压缩包中分发。
压缩包不包含视频编码工具；首次重新渲染时按上面的命令下载到本项目目录即可。
