二、哪些是我们自己做的
参赛工程/开发源码/passes/opt/pmux_opt.cc：新增 PMUX 优化 pass。
参赛工程/构建工具/PMUX优化补丁.patch：相对同基线原版的完整算法与集成补丁。
参赛工程/自研代码在哪里.txt：逐项说明自研算法、官方主体、共同环境修复和验证适配。
参赛工程/验证脚本、等价验证、通用验证：本项目配套入口、适配审计、统计与自建测试。
Yosys、ABC、EQY 等求解和综合工具本身属于上游官方软件，不是我们的原创工具。

三、怎样重新运行
保留参赛工程的完整结构。需要 Windows x64、Python 3.10+、完整 Git for Windows。
进入“参赛工程”文件夹，在终端执行：
  python "一键复验.py" --阶段 配置
  python "一键复验.py" --阶段 等价
“等价”会实际重跑九例两版面积及 EQY，不会只读取旧 PASS。
完整测量执行：python "一键复验.py" --阶段 全部
新结果写到工程旁的“复验输出/时间戳”，不覆盖原证据。

五、结果怎样理解
面积口径为 LUT + NOT：九例 2389→2115，总量下降 11.4692%。
逐例下降百分比的算术平均为 14.0805%，它不是总量下降比例。
九例无面积反增，DFF 和顶层 I/O 不变，EQY 为 9/9 PASS。
EQY 基于 ABC 后/map_cells 前网表及已披露的触发器适配与初始化处理。
PASS 表示该验证配置下功能等价，不代表网表文本相同或组委会最终认证。
旧测试、当前版本测试和视频展示分别标明，不能把整理上传算作一次新的运行。

六、怎样下载完整参赛包

提交材料中的文档、介绍视频中的成片与配音材料可以按需要单独下载。
正式归档与后来编辑的文档若存在差异，以仓库材料说明为准，不能把冻结包的哈希套用到其他文件。

七、哪些文件不要单独移动
不要只复制 yosys.exe 而丢失 DLL 和 share 目录。
不要删除官方许可证、源码来源与原始证据。
不要把新编译出的程序与旧版成绩混用；新程序需要重新测量和验证。
原始日志中的旧绝对路径仅用于追溯，重新运行请使用“一键复验.py”。
