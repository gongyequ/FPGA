# PMUX 结构优化参赛工程

本仓库整理了 2026 年全国大学生嵌入式芯片与系统设计竞赛 FPGA 赛道“多路选择器 PMUX 结构优化”的最终代码、设计文档、验证记录和介绍视频。项目基于 **Yosys 0.69+286**，新增可通过 Tcl 调用的 `pmux_opt` 命令，优化通用 PMUX 结构，并提供优化前后资源统计与 EQY 形式等价复验入口。

当前归档版本：**2026-11-04，B 臂嵌套吸收 + 统一 ABC F4c 配置**。固定上游提交为 `37f25dae90177888ac89573be92c3826da71f26e`。原版与优化版共同应用了 Windows Tcl 环境兼容修复，该修复不计为 PMUX 优化收益。

## 自研功能

新增 pass 位于 `开发源码/passes/opt/pmux_opt.cc`，在 `synth_intel` 原有 `peepopt; opt_clean` 后、`cmp2lut` 前插入一次：

```tcl
pmux_opt -order-decode -flatten-fallback -uniform-abc -flatten-data-arm
```

主要实现固定零选择臂删除、相同输出位列共享、控制译码稳定排序、默认 A 支嵌套合并及 B 臂嵌套吸收。B 臂规则在满足完整总线连接、单消费者和成本上限等条件时，将嵌套的数据选择改写为数据选择与较窄的控制选择。变换不依赖测试用例名称，不增加寄存器，不修改时钟、复位或官方 RTL 输入。

四态行为按本项目固定的官方 `simlib` 模型进行分析与补充测试；对不满足保护条件的结构保持原状。性能保护限制合并规模与次数，默认关闭的研究选项仍保留在源文件中，以维持源码与已验收二进制的一致性。

统一 ABC F4c 是调用官方 ABC 的参数配置，使用一次 ABC 映射。总体面积收益来自 PMUX 结构规则与这项统一配置的组合，不能全部归因于单独的 B 臂规则。

在已有 `pre_pmux.il` 输入的 Yosys Tcl 脚本中，可以这样调用：

```tcl
yosys -import
read_rtlil pre_pmux.il
pmux_opt -order-decode -flatten-fallback -uniform-abc -flatten-data-arm
stat
write_rtlil after_pmux.il
```

## EQY 证明范围

实际求解使用官方 EQY/Yosys，配套 Python 脚本负责输入准备、工具定位、统计和记录。验证输入为 **ABC 后、`map_cells` 前**的网表，经受限 `dffeas` 逆映射适配；两侧均执行 `opt_clean` 和 `setundef -zero -init`，已知初值保持不变。只匹配顶层 I/O，并将输出锥合并，使用 SAT k-induction 策略，深度参数为 20。

**PASS 表示该公开配置下优化前后功能等价，不表示网表文本相同，也不表示无条件的全流程四态等价。** 它不是仅运行 20 周期的波形仿真；补充的四态仿真与边界测试另见 [通用验证](参赛工程/通用验证)。其中历史冻结 F2c 测试已单独标识，不能当作当前 B 臂版本新跑的记录。

本地验证和文档中的指标不是组委会最终认证；最终评价以赛事实际验收为准。验证准备代码与适配审计见 [等价验证](参赛工程/等价验证)。

## 在 Windows 上复验

需要 Windows x64、Python 3.10 或更新版本，以及完整 Git for Windows。保留 `参赛工程` 的完整目录结构，不能单独移动 `yosys.exe`；官方 EDA/EQY 最小运行闭包已随工程提供。该闭包面向本项目使用的 EQY/Yosys SAT 策略；选择其他求解策略时需另备所要求的官方求解器。

在仓库根目录打开 PowerShell：

```powershell
cd "参赛工程"
python "一键复验.py" --阶段 配置
python "一键复验.py" --阶段 等价
```

“等价”阶段会重新运行九例原版/优化版面积测量及真实 EQY。新记录默认写到 `参赛工程` 目录旁的 `复验输出/时间戳`，不会覆盖冻结证据。

```powershell
# 只测面积
python "一键复验.py" --阶段 面积

# 完整面积、等价与性能复测
python "一键复验.py" --阶段 全部

# 查看输出路径及单独性能阶段的参数
python "一键复验.py" --help
```

单独运行性能阶段需要 `--已有证据` 指向本入口先前产生的结果目录。正式性能测量时请关闭其他编译、综合和仿真负载。

若 Git 未在 PATH 或常用安装位置，可设置当前终端的 `PMUX_GIT_USR_BIN` 指向本机 Git 安装目录中的 `usr/bin`。入口使用临时路径映射处理中文路径，不修改系统 PATH 或注册表。详细环境说明见 [提交说明](参赛工程/提交说明_先读.txt)。
