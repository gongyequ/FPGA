第一段 设计思路 约40秒
画面：技术文档第3页整体架构图。
讲解：
我们的作品面向FPGA综合中的并行多路选择结构。目标是在保持电路功能等价的前提下，减少综合后的逻辑资源。
工程基于官方Yosys零点六九版本，实现自研pmux_opt命令。输入仍使用官方测试RTL，后续映射和形式验证仍由官方ABC和EQY完成。
我们主要改进PMUX的连接结构和统一映射配置，不新增寄存器，不按测试用例名称进行特判。

第二段 展示自定义Tcl命令 约50秒
先在编辑器或记事本中打开同目录command_demo.tcl。
核心代码：
  yosys -import
  read_rtlil pre_pmux.il
  pmux_opt -order-decode -flatten-fallback -uniform-abc -flatten-data-arm
  stat

然后切到终端执行：
  python 录制演示.py 命令

脚本会真实准备官方ZIP04用例的前处理网表，再通过Yosys -c执行上面的Tcl脚本。
屏幕重点停留在：
  PMUX data-arm flattening: merged 2 single-use nested data arms.
  ... reordered 8 decoder tables.

讲解：
yosys -import把Yosys注册的命令导入Tcl，随后可以直接调用pmux_opt。
order-decode表示译码分支稳定排序；flatten-fallback用于嵌套默认分支；flatten-data-arm用于嵌套数据分支；uniform-abc负责全用例统一的官方ABC参数。
这里的真实日志显示，本用例发生了两次嵌套数据分支合并和八处译码表重排。

注意：命令演示单独准备前处理网表。下面正式面积对比从原始RTL重新开始，synth_intel自动调用同一自研命令，不额外手工插入一次。
本例日志里零臂清理、同列共享、默认分支合并的次数为0，不应把它们讲成本例已经发生的收益。

第三段 解释优化算法 约70秒
画面：设计文档第4页的公式与图2，第5页的流程图。
讲解：
先识别PMUX的默认输入、数据分支、选择信号和输出之间的连接关系。
本次新增规则关注一种结构：外层的一个数据分支，又连接了一个内层PMUX。
如果内层输出是完整总线，并且只被这个外层分支使用，我们就可以把宽数据选择层合并。
但控制信号不能直接用普通与门替换。我们额外生成窄PMUX控制逻辑，使外层未选中时内层被屏蔽，选中时正确转交默认数据或对应分支，并保持固定官方模型的X和Z行为。
同时设置位宽成本条件、最多十六个合并分支，以及每种嵌套规则每模块最多三十二次合并。保护条件不满足时保留原结构。
后续使用同一个官方ABC程序和全用例一致的F4c参数进行映射。

第四段 面积对比 约60秒
终端执行：
  python 录制演示.py 对比

程序真实运行两版Yosys，显示各自stat原始统计段，并保存实际IL/JSON网表。
重点指向：原版371个$lut、16个dffeas；优化版292个$lut、16个dffeas。
讲解：
现在对同一个官方反馈型ZIP04用例进行综合，输入、默认参数和工具基线保持一致。
原版使用三百七十一个LUT，优化版使用二百九十二个，减少七十九个，下降百分之二十一点二九。
触发器都为十六个，顶层接口也保持不变。
这里按照答疑统计LUT加取反单元，本例取反单元为零；不能把屏幕上的全部cells数量直接说成面积指标。

stat中的全部cells是387→308，因为还包含16个触发器；赛事逻辑资源口径是371→292。

接着执行：
  python 录制演示.py 九例

讲解：
这是已完成的全部九个官方用例验收记录。没有单例LUT反增，逐例下降百分比的平均值为百分之十四点零八。
九例资源总量由两千三百八十九降至两千一百一十五，总量下降百分之十一点四六九。逐例平均和总量下降是两个不同指标。

“九例”步骤读取现有完整验收证据，屏幕已明确标注；不要把它说成刚才现场重跑了九例。

第五段 EQY形式等价结果 约50秒
终端执行：
  python 录制演示.py 等价

该步骤对“对比”刚生成的两份真实网表重新运行官方EQY，不是播放旧PASS。
屏幕重点停留3至5秒：
  Successfully proved designs equivalent
  DONE (PASS, rc=0)

讲解：
这里将刚才两版综合产生的网表作为gold和gate输入，调用真实官方EQY进行SAT归纳验证。
工具输出Successfully proved designs equivalent以及PASS，表示在文档披露的触发器适配和初值、未知值归一化策略下，两份网表功能等价。
网表的结构和单元数量已经不同，因此我们说的是功能等价，不是网表文本完全相同。
全九例的正式EQY记录均已通过，并随代码保存。

简短收尾 约10秒
本作品实现了可通过Tcl调用的PMUX结构优化命令，在公开九例上取得平均百分之十四点零八的逻辑资源下降，并提供源码、原始日志和可复验的形式验证记录。

录制时保持的准确表述
1. 不把EQY PASS说成未经归一化的任意四态输入全证明，也不说组委会已认证。
2. 不说“所有用例都减少了面积”：RAR1和RAR3没有减少，但没有反增。
3. 不把“总cells”和“LUT加取反”混为一谈；不把局部PMUX个数当最终LUT面积。
4. 不把21.29%说成九例平均，它只属于ZIP04；九例平均是14.08%。
5. 不把普通运行耗时当正式性能成绩；本视频主要展示命令、面积和EQY。
6. 不需要讲完所有源码。展示Tcl命令、算法图、真实资源表和真实PASS即可形成完整证据链。
